## 📌 Project Overview & Objectives
- **Project Name:** iHeal (A wellness e-commerce platform built on WordPress)
- **URL:** [https://ihealwehear.site/](https://ihealwehear.site/)
- **Background:** This is a collaborative project developed by a student group for the **Capstone Project 1** course. It aims to migrate a supplement store from third-party marketplaces (Shopee, Facebook) to an independent site to reduce platform fees, own customer data (CRM), and centralize fragmented order management.
- **System Goals:** 
  - Maximize profits and build custom customer loyalty programs.
  - Establish a secure multi-role back-office system across dedicated subdomains (**Customers, Sales Agents, Brand Operators**) to streamline order fulfillment.
  - Integrate a wellness knowledge hub (Blogs, Podcasts, Digitized Books) and automated AI Chatbots.
